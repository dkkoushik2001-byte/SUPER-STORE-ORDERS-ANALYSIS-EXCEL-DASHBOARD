# 📊 Super Store Orders Analysis Dashboard

## 📌 Overview
This project is an Excel Dashboard created to analyze Super Store sales data and generate business insights through interactive visualizations.

## 🎯 Objectives
- Analyze Total Sales and Profit
- Track Orders and Units Sold
- Compare Sales by Region, Category, and Segment
- Identify Monthly Sales Trends

## 🛠️ Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design

## 💡 Key Insights
- Identified top-performing regions and categories.
- Analyzed sales distribution across customer segments.
- Tracked monthly sales performance trends.
- Visualized business performance using an interactive dashboard.

- Data Analysis
- Data Cleaning
- Data Visualization
- Dashboard Development
- Business Reporting
